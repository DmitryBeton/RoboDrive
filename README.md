# RoboDrive

Учебный тренажер управления двухколесным роботом для iPhone и iPad.
Автор: Чалов Дмитрий Максимович, группа 251-325.

## Возможности

- Практика: первые движения, повороты, узкий коридор, объезд колонн, точная остановка.
- Описание задания, схема полигона, условия прохождения и лучший успешный результат.
- Свободный заезд на любом из пяти полигонов, без лимита касаний.
- Полигон сверху, джойстик, кнопка остановки, максимальная скорость от 0,3 до 2 м/с.
- Пройденная траектория, контрольные точки и подсчет касаний.
- Пауза и автоматическая остановка при уходе приложения в фон.
- Результат: время, путь, касания, траектория и подсказка.
- Локальная история заездов, удаление отдельного результата с подтверждением.
- Чувствительность поворота, вибрация, траектория, системная/светлая/темная тема.
- Адаптация управления к вертикальному и горизонтальному расположению экрана.

Все данные хранятся на устройстве. Сервера, учетной записи и сторонних библиотек нет.

## Как пользоваться

Откройте задание в «Практике», прочитайте условия и нажмите «Начать задание», затем «Поехали».
Джойстик вверх/вниз управляет движением вперед/назад, влево/вправо — поворотом.
Отпускание джойстика и кнопка «Стоп» обнуляют команды обоим колесам.

Контрольные точки нужно проходить по порядку. Для успешного финиша остановитесь внутри зеленой зоны минимум на 0,35 секунды.
При превышении допустимого числа касаний попытка заканчивается. Упражнение с нулевым лимитом заканчивается при первом касании.
В свободном режиме завершение и сохранение доступны из меню паузы. Выход крестиком прерывает текущую попытку без сохранения.

Лучший результат задания выбирается сначала по наименьшему числу касаний, затем по времени.
При ошибке сохранения на экране результата появляется сообщение и кнопка повторной попытки.

## Технологии и структура

- SwiftUI: навигация и экраны (`ContentView.swift`, `Features/`).
- SpriteKit: отрисовка полигона и векторного робота (`Simulation/RobotScene.swift`).
- Чистая модель на Swift: движение, контакты, последовательность точек и финиш (`Core/RobotEngine.swift`).
- JSON/Codable: встроенные задания (`Core/Resources/missions.json`).
- Observation: состояние сеанса (`Simulation/DriveSession.swift`).
- SwiftData: результаты и траектории (`Persistence/Attempt.swift`).
- AppStorage: настройки.
- Swift Testing: отдельный пакет ядра, который проверяется на Mac без симулятора.

Модель использует метры и секунды. Полигон: 12 × 8 м. Расстояние между колесами: 0,48 м.
Линейная скорость равна `(left + right) / 2`, угловая — `(right - left) / track`.
Расчет выполняется с подшагами до 1/120 секунды. Один кадр ограничен 0,1 секунды, чтобы задержка отрисовки не телепортировала робота.
Коллизия проверяется окружностью радиуса 0,32 м. Непрерывное давление на стену считается одним касанием.
Графика независима от расчетов. Реалистичная инерция, трение и проскальзывание в эту версию не входят.

Робот, сетка и маркеры рисуются программно; внешних спрайтов нет.
Иконка воспроизводится командой `swift Scripts/GenerateIcon.swift` из корня проекта.

## Открытие и проверка

Откройте `RoboDrive.xcodeproj` в установленном Xcode. Исходный проект использует новый формат `project.xcproj` и deployment target iOS 27.2; для него требуется соответствующий Xcode/SDK.
Для установки на реальный iPhone выберите свою команду подписи в Signing & Capabilities.

Проверка математической модели без запуска приложения:

```sh
swift test -j 2
```

Сборка для устройства без запуска симулятора и подписи:

```sh
xcodebuild -project RoboDrive.xcodeproj -scheme RoboDrive \
  -destination 'generic/platform=iOS' -jobs 2 CODE_SIGNING_ALLOWED=NO build
```

Сборка не заменяет проверку на устройстве. Перед демонстрацией нужно проверить управление, поворот экрана, паузу при уходе в фон и сохранение истории после перезапуска на iPhone.
